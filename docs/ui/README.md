# Interface images

The repository README uses:

- standalone-live.jpg: running macOS standalone window, with the embedded E-4 logo, captured through the native UI screenshot API.
- installer-live.jpg: running graphical macOS installer, with the same logo; captured before installation.
- controller-settings-live.jpg: running MIDI learn/controller settings dialog.
- chord-settings-live.jpg: running chord-bank settings dialog.
- plugin.png: native JUCE plug-in component snapshot, rendered by e4_ui_preview; this is not an Ableton floating-window capture.

Settings shown in live captures are existing user/example values; output remains disconnected and clock stopped during capture. No audio or device performance result is implied. Dialogs were cancelled after capture, preserving settings.

Other PNGs are native component previews generated by:

```sh
cmake --build build-check --target e4_ui_preview
./build-check/e4_ui_preview_artefacts/Debug/e4_ui_preview "$PWD/docs/ui"
```

The preview utility opens no MIDI devices and does not load/save standalone preferences. The original icon is embedded as binary image data in the shared standalone/plug-in header and graphical installer, in addition to the OS bundle icon.

The component previews now show the compact 56-pixel header and taller keyboards (94 pixels in the plug-in, 122 in standalone). The live JPEG captures retain the published 0.1.0 layout.
